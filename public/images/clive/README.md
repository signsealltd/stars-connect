# Official Clive artwork

`ask-clive.png` is the unchanged supplied 1254 × 1254 transparent source. Do not crop, recolour, stretch or regenerate it.

`ask-clive.webp` is a proportional 440 × 440 WebP export (quality 88), sufficient for the welcome illustration at twice its displayed size. The UI uses a picture source with PNG fallback, preserves the complete artwork with `object-fit: contain`, and keeps all instructions and controls in accessible HTML.

The full illustration is used only in the welcome state; the header retains a small avatar after a question is sent. Guided lessons hide the floating assistant so the highlighted page control remains the focus.
