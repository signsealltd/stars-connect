# V1.16.0 - Active client attendance export

Clients now offers **Export active clients (PDF)**. The authenticated, audited download includes all active, non-archived clients independently of the screen's search and filters. It uses full names in alphabetical order, the internal reference shown in Clients, and an empty attendance-count cell for each person.

The printable A4 landscape PDF repeats headings on every page, includes page numbers, and provides a blank period field. No attendance or client records are changed. No database migration is required.

The export requires the existing Clients view permission and uses private, non-cacheable responses. Only names and references are exported.
