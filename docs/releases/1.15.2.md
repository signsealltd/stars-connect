# V1.15.2 — Calendar activity management

Previous version: V1.15.1. Open a calendar date to find Edit activity and Cancel activity on eligible activity cards. The existing form opens with the saved title, type, date, times, location, description and staff/client selections. Changes affect this occurrence only and update the shared records used by the Staff Area calendar. Cancelled activities disappear from the planning view while their history remains available.

Calendar manage and Operations edit are required for editing; changing assignments requires the respective staff/client assignment capability. Cancellation uses the existing Operations cancel capability and status transitions. Activities already active, in post-operation review, completed or cancelled cannot be edited here. Training and other source-managed calendar records retain their existing management links.

Edits check employment availability, overlapping activity assignments, organisation scope and the saved update timestamp. They return the activity to Planning with readiness requiring review and reset staff confirmations. Removed assignments/attendees are retained with removed/cancelled status; audit entries preserve previous values and staff receive schedule notifications. Editing one recurring occurrence separates its editable details from the shared operation, retaining its occurrence ID and leaving other occurrences unchanged.

No schema migration. Validation covers editing and cancellation through the local UI/API, UK time conversion, shared assignments, attendee removal without loss of history, audit and notifications, stale edits, protected states, unauthenticated access, desktop/tablet presentation, automated regression tests and production build. No live activities were changed during verification.
